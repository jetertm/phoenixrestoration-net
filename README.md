# Phoenix Restoration LLC

Marketing site for Phoenix Restoration LLC at [phoenixrestoration.net](https://phoenixrestoration.net/).

Static HTML, CSS, and JavaScript. There is no build step. The intended host is Cloudflare Pages, with this repository as the site root (`index.html` at the project root).

Service area: 10 central Alabama counties — Chilton, Autauga, Elmore, Shelby, Bibb, Coosa, Dallas, Perry, Lowndes, and Montgomery.

## Pages

| File | Page |
|------|------|
| `index.html` | Home |
| `services.html` | Services |
| `about.html` | About |
| `team.html` | Team |
| `area.html` | Service area |
| `contact.html` | Contact |

Shared files: `styles.css`, `site.js`, `favicon.svg`, and `assets/`.
